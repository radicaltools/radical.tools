From Marta:

PayLine raised their fees. We are moving to NordPay, but I want to be able
to switch back, so both must work and which one is used is a setting.

From our hosting company: the setting is the environment variable
`PAYMENT_PROVIDER`, `a` for PayLine (the default) or `b` for NordPay.
NordPay's address is in `PAYMENT_PROVIDER_B_URL`.

NordPay:

```
POST {PAYMENT_PROVIDER_B_URL}/v2/payments
{ "amount": { "value": 1999, "currency": "EUR" }, "orderRef": "…" }

200 { "id": "pay_…", "outcome": "approved" | "refused" }
```

```
POST {PAYMENT_PROVIDER_B_URL}/v2/payments/{id}/refunds
{ "amount": { "value": 500, "currency": "EUR" } }

200 { "id": "rf_…", "outcome": "approved" }
```

Both can fail with a 5xx answer.
