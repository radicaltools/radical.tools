From Marta:

Customers must be able to send goods back, a whole order or a part of it.
The goods go back into stock and the customer gets the money back through
PayLine.

PayLine refunds:

```
POST {PAYMENT_PROVIDER_URL}/refunds
{ "chargeId": "ch_…", "amountCents": 500 }

201 { "refundId": "re_…", "status": "succeeded" }
```

It can fail with a 5xx answer, as charges can.
