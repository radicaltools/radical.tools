# Step 6 — discount codes

- **HD-31:** the percentage is a whole number from 1 to 90. A code is 3 to
  20 letters and digits, unique.
- **HD-33:** upper and lower case do not matter: `spring` and `SPRING` are
  the same code, when creating and when ordering. It is kept and shown in
  upper case.
- An order with a code that does not exist is refused.
- **HD-32:** the discount is the order's value times the percentage,
  rounded down to a whole cent. The order shows its value before the
  discount, the discount, the code, and the total to pay.
- The customer is charged the total after the discount.
- **HD-34, returns of a discounted order:** the customer gets back what
  they paid for the goods, not the list price: value of the returned lines ×
  total paid / value before discount, rounded down. The return that
  completes the order gives back whatever is left, so that the refunds add
  up exactly to what was paid.
- An order without a code has a discount of zero.
