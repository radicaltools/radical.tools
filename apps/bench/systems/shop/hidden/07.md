# Step 7 — NordPay

- With NordPay, `orderRef` is the order's id and the currency is always
  `EUR`. `approved` means paid, `refused` means declined. The id NordPay
  returns is kept as the payment's provider reference, and refunds go
  against it.
- A 5xx answer or no connection is "provider unavailable", with the same
  consequences as for PayLine.
- R3 stands: both providers are handled in the same single part of the
  code, and only that part reads their addresses and the setting.
- Nothing else about the shop changes.
