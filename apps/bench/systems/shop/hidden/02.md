# Step 2 — several warehouses

- The warehouse the company has today is called `MAIN`. All stock so far
  is there. An entry made without naming a warehouse goes to `MAIN`.
- **HD-19:** a warehouse has a code and a name. The code is 2 to 10
  characters, upper-case letters and digits, and unique.
- Stock figures are needed per warehouse and in total. R2 holds per
  warehouse too: what is available in one warehouse never goes below zero,
  and an adjustment down is refused when it would go below what is reserved
  in that warehouse, even if other warehouses have plenty.
- Every stock movement says which warehouse it happened in.
- **HD-17, where an order line is reserved:**
  1. If at least one warehouse can cover the whole line, take all of it
     from one: the one with the most available; on a tie the code that comes
     first alphabetically.
  2. Otherwise split: as much as possible from the warehouse with the most
     available, then the next (ties: code first alphabetically).
- **HD-18:** an order is refused only when all warehouses together cannot
  cover a product.
- The order must show, per line, how many units are reserved in which
  warehouse.
- Shipping records one movement per line and warehouse, in that warehouse.
- Cancelling frees the stock in each warehouse.
