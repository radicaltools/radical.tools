# Step 20 — what goes together

R8 stands for every combination: whatever comes together on a line, the
line stops at its floor.

## Customers of a group

- **HD-106:** a customer who is in a group gets no promotions: on an order
  placed on their account no promotion counts, whichever products are on
  it — also products that are not on the group's price list and are bought
  at the normal price.
- **HD-107:** such a customer cannot use a discount code. An order on their
  account that names a code is refused, so that the web shop can tell
  them; nothing is reserved. (It is not accepted with the code quietly
  left out.)
- It is the group that decides, not the price list: a group without any
  prices yet is treated the same way.
- An order without an account under a wholesale customer's e-mail address
  is an ordinary order (HD-91): normal prices, promotions and codes count.

## Everybody else: promotion and code

- **HD-108:** a code does not count on a line that got something off from a
  promotion. Its percentage is worked on the value of the other lines only
  (rounded down, HD-32) and is split over those lines. This replaces the
  rule of step 19 that the code is worked on what is left after the
  promotion.
- **HD-109:** an order where every line got a promotion is still accepted
  with a code: the code is on the order and takes nothing off.
- **HD-110:** what decides is whether the promotion really took something
  off the line. A product that is in a running promotion but did not earn
  it on this order (two units where three are needed, a set that is not
  complete) is an ordinary line, and the code counts on it.

## Points

- **HD-111:** points go with everything: with a price list, with a
  promotion, with a code. They are the customer's own money. As before
  they pay for at most half of what is left after everything else, and
  they stop at the floor (HD-96).

## What the order shows

- The value at the prices used, what promotions took off, what the code
  took off, what points took off, the VAT, and the total. The total is the
  value minus the three amounts taken off.

## Not decided

A code that is only valid for some products, the customer choosing between
the promotion and the code, staff discounts.
