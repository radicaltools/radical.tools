Architecture modelling,
not just drawing.

Diagrams go stale because the drawing is the document. Radical.Tools makes the model the document — every view is derived from it, always consistent.

Open Studio — free, in the browser Explore the Hub

No account. No cloud. Your models stay as files on your disk.

Metamodel01 The vocabulary: which element and relation types exist, and what may contain what. C4, C4 + DDD and C4 + Governance ship built in — extend or replace. Model02 One graph of nodes and relations — the single source of truth. Add an element once and it exists in every view. No drift between levels. Views03 Six readings of the same model: Structure, Flow, Hierarchy, Table, Matrix and Wiki. Each keeps its own layout and filters; the model stays shared. Milestones04 Name any state of the model, diff two milestones side by side, restore any of them. Architecture decisions get a timeline.

Also in the box

  • Governance as first-class elements. ADRs, fitness functions and EARS requirements live in the model and link to what they constrain, implement or supersede.
  • AI that edits the model, not the picture. Ask questions, find gaps, or describe a change in plain language and apply it as a structured patch. Claude, OpenAI, Gemini or local Ollama — your key, nothing proxied.
  • Concept Hub. A curated catalogue of patterns, blueprints, requirements, ADRs and fitness functions — explore them in the real viewer, then import with one click.
  • Presentations from views. Sequence structure, flow and hierarchy views into a deck; flow views replay interactions step by step.
  • Plain files, no lock-in. A single JSON file or a git-friendly folder of Markdown — one .md per element. Diff it, review it, script it.
  • Desktop or browser, same code. Electron app for local folders and file watching; the web build for zero-install use. Also a VS Code extension.
