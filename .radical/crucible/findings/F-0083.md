## Steps

1. Seed the blueprint bp-ecommerce-platform with a view of all its elements, open it in Designer
2. Click Smart Layout and watch the 'Stop · N moves · <move>' button

## What differs

```text
Expected: The Stop button keeps one width and place while Tidy runs; the move's description is shown beside it or in a tooltip, and the other controls stay put
Actual: The button goes from 75 to 656–981 px wide as the move description changes, recentring the bar (Fit All x 622 -> 351); a Playwright click aimed at Stop waited for it to settle, landed after the run and started a second one
Seen: 2 of 2
Where it probably comes from: the Smart Layout / Stop button in the canvas controls (CanvasControls) shows the running move's description in its label
A test that would catch it: apps/e2e/tests/studio/layout.spec.ts: while Tidy runs on a 45-element view, the Stop button's bounding box stays the same at every sample
```

## Fixed (2026-10-26)

The Stop button keeps the idle button's width and place, the move under way is shown in a status line above the canvas controls, and the report button keeps its place, hidden, during a run.
