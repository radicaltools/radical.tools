## Steps

1. Fresh browser profile, open Studio at /
2. The Setup wizard opens at Theme: choose nothing, do not skip
3. Close the tab (or reload) and open Studio at / again

## What differs

```text
Expected: The wizard opens again: it was neither finished nor skipped
Actual: No wizard. After the first load localStorage holds only the boot-seeded 'Untitled' doc (no settings, no theme); on the return radical-studio-settings is written with setupDone:true and the Welcome screen shows Recent: Untitled
Seen: 2 of 2
Where it probably comes from: guess: apps/studio/src/renderer/src/firstStart.ts usedBefore() counts the document the store seeded on the first load (documentStore boot seed); isBootSeeded() only knows it in memory, so it is lost on reload
A test that would catch it: apps/e2e/tests/studio (setup wizard spec, firstStart: true): open /, wizard visible; reload; the wizard is still visible and setupDone is not stored; after Skip setup and a reload it stays closed
```

## Fixed (2026-11-15)

A first start stores setupDone: false so the wizard opens again until finished or skipped, and the first visit's model is marked seeded in the index so it is not listed or counted as use.
