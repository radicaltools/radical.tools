## Steps

1. Sample, Designer, Core Banking: select Fraud Detection, Delete, Remove from model
2. Milestones: v3 draws it on Core Banking (14)
3. Milestone properties of v3, Restore to live

## What differs

```text
Expected: Core Banking draws 14 elements with Fraud Detection, as v3 showed it
Actual: The live model has 30 elements with ctn-fraud, but Core Banking draws 13, no saved view lists ctn-fraud; v3 opened again still draws 14
Seen: 3 of 3
Where it probably comes from: guess: restoreSnapshot ignores snap.views (the lists the milestone keeps since F-0053). Sibling of IMPROVEMENTS item 286 (view per element only)
A test that would catch it: packages/ui/tests/milestoneDeletedSince.test.ts: delete an element a milestone holds on the live model, restoreSnapshot(milestone): every view whose copy in the milestone lists it lists and draws it on the live model
```

## Fixed (2026-10-26)

Restore to live makes the milestone's view lists and its own views the live ones, so Fraud Detection is drawn on Core Banking again.
