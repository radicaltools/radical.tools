## Steps

1. Bookstore fixture moved to a folder; an MCP server (apps/mcp/dist) on a copy runs Assay on two small repositories
2. open the Assay panel, click Follow on the canvas
3. double-click Customer, type ' (online)' into Name
4. agent: assay_apply with a C4 plan, then create_view 'Shop' of those elements
5. Studio switches to Shop and the card closes; type ' shopper'

## What differs

```text
Expected: Following waits while a field has the focus (or the card keeps it); the name saved is 'Customer (online) shopper', as it is without Follow
Actual: Shop opened, card open: 0, focus on BODY; saved label 'Customer (online)' (' shopper' lost); without Follow the card stays and the full name is saved
Seen: 3 of 3
Where it probably comes from: apps/studio/src/renderer/src/persistence/followAgent.ts onOutsideEditLoaded: setActiveView clears the selection and the card; pause() only on camera and view switches (guess)
A test that would catch it: apps/e2e/tests/studio/folders.spec.ts: follow on from an Assay run panel, double-click an element, type in Name, folder.write a view showing a changed element + agent-activity.json → card still open with Name focused, whole typed name saved
```

## Fixed (2026-11-15)

Follow the agent waits while a text field has the focus and follows what came meanwhile once the field lets it go, so the card and the typed name stay.
