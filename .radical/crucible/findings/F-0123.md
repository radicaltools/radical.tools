## Steps

1. bookstore fixture, Designer, theme System, OS dark
2. F5 to start the presentation
3. The OS turns light (emulateMedia colorScheme light)

## What differs

```text
Expected: Studio turns light during the presentation, as it does in Designer
Actual: data-theme stays 'dark' (body rgb(38,43,54)) for as long as the presentation plays; it turns light only after Escape stops it. In Designer the same OS change applies at once
Seen: 2 of 2
Where it probably comes from: guess: apps/studio/src/renderer/src/components/Toolbar.tsx sets data-theme in an effect, and App.tsx unmounts the Toolbar while presenting (!isPresenting && <Toolbar />)
A test that would catch it: apps/e2e/tests/studio (theme spec): theme System, emulateMedia dark, F5, emulateMedia light; html[data-theme] is 'light' while .mode-presenting is shown
```

## Fixed (2026-11-15)

App applies the theme (useApplyTheme) instead of the Toolbar, which is gone while presenting.
