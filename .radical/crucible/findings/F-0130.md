## Steps

1. Bookstore fixture moved to a folder (Models → Move to a folder…)
2. an agent's finished Forge run in .state/forge-run.json and an active Assay run in .state/assay-run.json
3. click the Forge button: the Forge run panel opens
4. click the Assay button: nothing changes
5. press Escape: the Forge panel closes and the Assay panel appears unasked
6. open the Assay panel, click the Forge button, close the Forge panel with ✕: the Assay panel comes back

## What differs

```text
Expected: The clicked button's panel shows and the other closes; closing a panel leaves none open
Actual: Assay click under the Forge panel: forge panel 1, assay panel 0; after Escape: forge 0, assay 1; after the Forge panel's ✕: forge 0, assay 1 (3 of 7 steps differ)
Seen: 2 of 2
Where it probably comes from: apps/studio/src/renderer/src/components/Toolbar.tsx: AgentAssayModal open={agentAssayOpen && !forgeOpen && !agentForgeOpen}; opening one panel never clears the other's flag (guess)
A test that would catch it: apps/e2e/tests/studio/folders.spec.ts: with forge-run.json (finished) and assay-run.json (active), open the Forge agent panel, click .qs-assay-toggle → Assay dialog visible, Forge dialog count 0; Escape → neither dialog
```

## Fixed (2026-11-15)

The Toolbar keeps one run panel, so the last clicked shows and closing leaves none open.
