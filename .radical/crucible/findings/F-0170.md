## Steps

1. Studio set up, Bookstore in this browser
2. Open /?hub=concern-authentication: the Welcome screen says Authentication waits
3. Reload
4. Open the model from Recent

## What differs

```text
Expected: The pack still waits after a reload and its import opens over the model picked
Actual: After the reload no pack waits; opening the model opens no dialog (address already http://localhost:4516/ before the reload)
Seen: 2 of 2
Where it probably comes from: apps/studio/src/renderer/src/App.tsx takeHubLink replaces the address at once (deliberate: 'so a reload does not ask again')
A test that would catch it: apps/e2e/tests/studio/hub-import.spec.ts: goto /?hub=concern-authentication, reload, expect the Welcome status, pick Recent, expect the concern wizard
```

## Decision (2026-11-15)

A pack from a Hub link waits across a reload of the Welcome screen until its import has opened; after that a reload asks nothing. To be written into the model's requirement on the branch that fixes it.

## Fixed (2026-11-15)

?hub= stays in the address until the pack's import opens, so a reload of the Welcome screen keeps the pack waiting, and a reload after the import asks nothing.
