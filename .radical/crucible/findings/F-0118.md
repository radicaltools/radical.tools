## Steps

1. Open the payments folder without deps.json (Open → Folder…), Designer, Landscape: 2 nodes, no Other models button
2. Write deps.json and .state/federation.json into the folder, as radical setup --depends-on + fetch do
3. Wait 20 s: still 2 nodes, no button
4. Reload: 4 nodes (bookstore, customer) and '1 other model'

## What differs

```text
Expected: Within a poll (2.5 s) Studio shows orders' elements and the Other models button, as it does for a new fetch of a model that already had deps.json
Actual: After 20 s: nodes [pay-clerk, pay-sys], no button; after a reload: [bookstore, customer, pay-clerk, pay-sys] and '1 other model'
Seen: 3 of 3
Where it probably comes from: apps/studio/src/renderer/src/store/documentStore.ts followFederation: the poll returns while last.texts.deps == null, so a model read without deps.json is never polled and polling stops once deps.json goes (guess)
A test that would catch it: apps/e2e/tests/studio/federation.spec.ts: openComposed with no deps.json and no federation, write both, expect studio.node('ord') visible and the other-models button within 10 s, no reload
```

## Fixed (2026-11-15)

Every watched folder model's federation files are polled, also without a deps.json, so a later setup and fetch, or a deps.json added back, reach the open model.
