## Steps

1. Bookstore fixture, Containers view, Viewer (or Presenter)
2. Hold Alt, draw a box from the empty inside of Bookstore over Web App, API, Orders DB
3. Alt-click API
4. Designer: box over Web App and API, then Alt-drag from API onto Payment Provider

## What differs

```text
Expected: Alt-click takes API out: [web, db]. Designer: web->payments and api->payments, nothing moves
Actual: Under API is .react-flow__nodesselection-rect; selection stays [web, api, db] in Viewer and Presenter. Designer: no relation and no notice; web and api dragged about 690 px right, Bookstore grows to 1251.8x428.2, payments and db pushed, saved
Seen: 2 of 2 viewer, 1 of 1 presenter, 2 of 2 designer drag
Where it probably comes from: packages/ui/src/components/Canvas.tsx onMouseDown (special key): findNodeId on React Flow's nodes-selection rect is null, so the gesture never starts and React Flow drags the selection
A test that would catch it: apps/e2e/tests/studio/selection-focus.spec.ts: after an Alt box over web, api, db, an Alt-click on api leaves [web, db] in Designer, Viewer and Presenter; nesting.spec.ts: after an Alt box, Alt-drag from api to payments makes both relations and moves nothing
```

## Fixed (2026-10-26)

The special key looks through React Flow's selection rectangle, so after a box selection a key-click takes an element out and a key-drag relates the whole selection without moving it.
