## Steps

1. A repository: package.json, src/index.ts, .git/, and its model payments in .radical/model (views Landscape, Payments table)
2. Welcome → New model → Storage: In a folder → Choose folder and create, picking the repository's root
3. Fresh start: Open → Folder… on the same repository

## What differs

```text
Expected: Studio says the folder is a repository that holds the model payments (in .radical/model) and asks, as it does before replacing a model folder, or refuses as Open does; nothing is written without a word
Actual: No question; written into the root: radical.md, views.json, metamodel.json, _layout.json, .state/.gitignore, .state/selection.json, .state/cache/model.json; Open → Folder… then opens 'model' with 23 views of the metamodel and no Landscape
Seen: 4 of 4
Where it probably comes from: apps/studio/src/renderer/src/store/documentStore.ts pickAndWriteFolder/mayWriteInto: session.readAll lists only model paths (radical.md, sidecars, nodes/), so a repository root reads as empty and modelFolderCandidates is not asked (guess; Move to a folder… takes the same path, from reading the code)
A test that would catch it: apps/e2e/tests/studio/folders.spec.ts: New model in a folder picked at a repository root whose .radical/model holds a model asks (or refuses) and writes nothing to the root when declined; packages/common/tests: a helper telling a picked folder holds a model at one of modelFolderCandidates
```

## Fixed (2026-11-15)

New model and Move to a folder… refuse, writing nothing, a folder with a repository's model below it (modelBelow), and ask before a folder of any other files.
