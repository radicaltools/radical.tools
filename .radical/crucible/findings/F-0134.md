## Steps

1. Shop folder with view Payments and milestone 'v1 Cards'; after it 'Pay in instalments' added and 'Take wallet payments' deleted (MCP)
2. Designer, Payments, Milestones › v1 Cards
3. Inspector › Requirement without scenario › Open on 'Pay in instalments'
4. Designer › double-click 'Take wallet payments' › Path

## What differs

```text
Expected: Open shows the requirement's card; Path shows the element's path or is disabled with a reason
Actual: Open: card text only 'Show on canvas ▾ Open wiki page ▾', no title; Path: enabled, switches to Inspector › Overview, path panel not shown, address ends /t/overview/tr/<id>/s/<milestone>
Seen: 2 of 2
Where it probably comes from: guess: Inspector.tsx lists liveBackup's nodes but ElementCard (packages/ui RightPanel) reads c4Nodes, the milestone's; tracing requires nodes[traceId] in the live model while the card offering Path reads the milestone
A test that would catch it: apps/e2e/tests/studio (folder model with a milestone): with the milestone shown, Inspector Open on a requirement added since shows its .pp-title; Path on an element only the milestone holds is disabled or shows the path
```

## Fixed (2026-11-15)

The Inspector holds the live model while a milestone is shown, and Path is disabled with a reason for milestone-only elements.
