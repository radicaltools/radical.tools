## Steps

1. bookstore fixture, Designer, Containers view
2. Click Orders DB
3. Settings > Setup… (or About Radical Studio, AI providers…, Models > Manage models…)
4. Press Delete
5. Close the dialog (Skip setup)

## What differs

```text
Expected: Delete does nothing while a modal dialog is open
Actual: 'Delete 1 element and 1 relation?' (Remove from model / Hide from current view / Cancel) opens behind the dialog in 4 of 4 dialogs; closing the dialog shows the prompt nobody asked for
Seen: 2 of 2
Where it probably comes from: guess: packages/ui/src/components/Canvas.tsx ReactFlow deleteKeyCode='Delete' ignores inModalDialog() (apps/studio/src/renderer/src/components/dialogKeys.ts)
A test that would catch it: apps/e2e/tests/studio (keyboard/dialogs spec): select an element, open each of Setup…, About, AI providers…, Models; press Delete; no .milestone-modal 'Delete …' prompt appears and the element stays
```

## Fixed (2026-11-15)

The canvas handles Delete itself behind one gate for canvas keys (modalDialogOpen/canvasKeysOff in keysHere.ts), used also by Escape, the hierarchy's Esc/Backspace and Studio's inModalDialog.
