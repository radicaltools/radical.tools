## Steps

1. Fresh browser profile, open Studio at /
2. Skip setup
3. Open: 'In this browser… 0 models'; pick Sample model
4. Reload, then Models > Manage models…

## What differs

```text
Expected: The Models dialog lists only the sample, as the Welcome screen counts it
Actual: The Models dialog shows All 2 / Browser 2: Fintech Banking Platform and Untitled (index entry seeded:true), while the Welcome screen's In this browser says 0 models
Seen: 3 of 3
Where it probably comes from: apps/studio/src/renderer/src/components/DocumentManager.tsx lists useDocumentsStore docs without the documents.isBootSeeded filter that WelcomeScreen.tsx applies (a guess: the list also feeds the dialog's counts)
A test that would catch it: apps/e2e/tests/studio/boot.spec.ts › first visit: Skip setup, open the sample, Models > Manage models…: one row, no 'Untitled', Browser count 1
```

## Fixed (2026-11-15)

One filter (usersModels) gives the models of the Welcome screen and the Models dialog, so the seeded Untitled is listed and counted nowhere.
