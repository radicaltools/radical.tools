type: "requirement"
label: "View shows exactly its filter"
action: "Studio and the MCP server shall show on that view exactly the elements the filter gives — the count in Filter, the Structure tree, the table, the wiki, the matrix, the hierarchy and the canvas agree, and Quick Search, model queries and slide focus count the same — drawing on a canvas, matrix or hierarchy only the relations the chain follows from an element to one under it, or every relation between the elements when the filter says so, and on a hierarchy only what the chain gives; a canvas holds an element whose container the filter does not give in that container drawn invisible, which no line ends at, and drawn open, also when it is folded on the model or was folded in the view; an element under several parents is drawn once, with a line to each; a change to the filter or to the model updates every view; an element added in a table, Warnier or wiki view, or dropped from the palette onto a canvas, gets the values its level's filter asks for, and Studio says when the view still does not show it; a relation drawn on a canvas whose filter is a chain is of a type the chain follows, or is refused with the reason; a matrix cell adds only a relation of a type the chain follows, never a second one; a hierarchy drilled into an element the filter leaves out shows its top; a flow view plays its sequence instead; a within filter on an element that is deleted goes from the view."
ears_type: "state-driven"
precondition: "a view's filter holds a chain of levels, or the view lists its elements"
rationale: "The filter is what the view is: Filter, Structure and the view used to count differently (Folder model in Studio: 15 in Filter, 17 on the canvas with the Conceptual and Modelling frames). Positions stay relative to containers, so a container the filter does not give stays on React Flow, invisible. Evidence: packages/common/src/viewPipeline.ts (viewShownNodes, withAncestors, chainDrawn, readPipeline), packages/layout/src/viewInput.ts (computeViewNodeSet, viewFrames, viewLayoutInput), packages/ui/src/store/diagramStore.ts (_sync, deriveRFNodes), apps/studio/src/renderer/src/components/MatrixView.tsx, TreemapView.tsx, apps/studio/src/renderer/src/navigation.ts, packages/common/src/ai/queryLanguage.ts, packages/common/tests/viewPipeline.test.ts, packages/layout/tests/drawnLines.test.ts, apps/e2e/tests/studio/view-pipeline.spec.ts; manual#view-steps"
