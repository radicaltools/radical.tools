In the Radical benchmark, the agent that built a system with Forge spent three times what the others did and got no better result; it could not skip a stage it did not need (Forge refused to jump over fitness functions, and a stage it did not want still took three calls). Working without Forge, writing the model as it learned, the same agent built the same step three times cheaper and better. Asked one by one: an agent skips any Forge stage with one call, saying why (for agents now; Studio shows it); by default an agent models as it works, and runs Forge only when the user asks for it.
