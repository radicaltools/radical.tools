"What is missing is a check that the requirement agrees with the need it was written from." Found in the Radical benchmark: the agent asked the client and was told that a product never received at a cost shows no average and its stock is worth 0, and that an order on an account carries the account's e-mail address; its requirement said the stock value is null, and its ADR that the order's e-mail is null, and the code followed them. The needs held only the request that started each step: the answers were summarised, or not written down at all. Asked: the agent checks itself, through the MCP server, before it writes the code.
Translated from Polish.
