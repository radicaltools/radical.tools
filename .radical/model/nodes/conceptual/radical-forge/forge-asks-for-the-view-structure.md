Remarks on Radical Forge (2026-10-18, translated from Polish):
- Forge works, but before it starts modelling it should ask about the structure of the model, meaning the structure of its views.
- As the default, propose what is done in the radical model (radical.tools' own architecture model: views of the metamodel's viewpoints in the folders Conceptual, Logical and Governance).
- Offer the default, a way to adjust it (leave views out), and the layer canvases Forge makes now.
- Create a view only when something lands in it, not the whole structure at the start.
