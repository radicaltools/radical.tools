type: "requirement"
label: "Read databases"
action: "the system shall read the database it connects to, with its engine, server and name where given (a connection string naming its engine's ODBC driver or OLE DB provider is a database even when its server and name are filled in at run time), an Access database DAO or a data control opens, named by the .mdb or .accdb file its path ends in, a constant of the module included, a database an SQL file creates (CREATE DATABASE, its quoted name whole), in the engine its dialect shows, as a database of the unit that holds the file, and the tables its SQL names, its SQL files create, its data controls read and its code opens by name (OpenRecordset, adCmdTable), as facts of that unit; a query in an entity language (JPQL in @Query or createQuery) names entities, not tables; a connection of an engine with neither name nor server is the database of that engine the unit names otherwise, the one database the repository's SQL scripts name (USE, CREATE DATABASE) for SQL Server, ODBC or MySQL (a dump's -- Database: header too), or no database, with a note; a name that is a placeholder (YOUR DATABASE NAME) names nothing, nor does a commented line of a configuration file; a user and password a database URL takes from the environment (postgresql://postgres:${POSTGRES_PASSWORD}@db/app) leave its server and name read; an SQLite URL names its file; a compose file's connection strings are those of the services it runs, not of the folder holding it; an environment file's DB_CONNECTION and DB_DATABASE are a database of its unit, the engine of Laravel's default connection (config/database.php) standing in for a DB_CONNECTION it lacks; a Prisma schema's datasource whose address the environment gives is a database of its provider's engine with no name; connection strings of three or more engines in one file are a library's templates, not databases it uses, and are left out with a note; Rails' config/database.yml is the database of the environment that runs (production, else development), its settings merged with those it inherits and ERB's ENV.fetch defaults read as their values; a ClickHouse URL, or ClickHouse's HTTP interface on port 8123 (http://events_db:8123/events), is a ClickHouse database; an Android app's Room database is the SQLite file Room.databaseBuilder names; a .NET project on SQLite names its database file by its settings' Data Source alone; Jet and ACE open the file their Data Source names, whatever it ends in (pharmacy.dll); a CI pipeline's files (.github, .gitlab-ci.yml, …) name the databases of its test jobs, not of the system"
ears_type: "event-driven"
rationale: "The data a system keeps is part of its architecture in old code and new; a VB6 form's SQL is often the only description of its tables."
trigger: "a unit's configuration or code holds a connection string (ADO or OLE DB, ODBC, JDBC, .NET, or a database URL), opens an Access database through DAO or a data control by its file, opens a table by its name, names tables in SQL, has an SQL file creating tables, or a VB6 form's data control with its record source"
