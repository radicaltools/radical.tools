Radical Assay: finding the model in an existing system, in one repository or several. Deterministic extractors read each repository's facts (workspaces, dependencies, deployment files, API descriptions, schemas, tests) with their evidence, and a linking step matches facts across repositories (APIs served and called, topics, packages); an agent interprets them into a C4 model, a domain model, state machines, processes, scenarios, requirements and needs, each marked as observed, inferred or a hypothesis for a person to confirm, and hands them to the server as a plan it checks and writes. The first version writes one central model and each code repository's .radical/radical.json; a federation of models comes later. Run again where a model exists, it reports where the code and the model differ.
