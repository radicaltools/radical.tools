After the Radical benchmark, where an agent read a group standard from a fetched model, built half of it and radical check still passed: "Every standard a system inherits should be tested in it too." Asked one by one: every accepted decision of a model the system depends on binds it unless the system waives it; a waiver is the system's own ADR, linked to the inherited one; a standard neither applied nor waived, or applied without a fitness function that checks it, is an error by default.
Translated from Polish.
