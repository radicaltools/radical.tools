consequences: "The four products have names that explain each other, and the testing loop (Crucible) and the gate (Hallmark) are told apart. Hallmark is long to type, which the permanent `radical check` alias softens. Implementing it touches the CLI (a new command name, help and usage text, the alias), the root npm scripts, the CI job's wording, CLAUDE.md, the manual, the Inspector's labels and the model's requirement and component texts; nothing in check.json or the report formats changes. A second name exists for a while; the alias keeps it harmless."
context: "With Radical Crucible named after Radical Forge's workshop (Forge builds the model, Crucible puts the code to the test against it), the third member, `radical check`, has a plain name that says nothing of what sets it apart: it measures how much of the model is backed by evidence (requirements with scenarios, verified requirements and ADRs, bound tests, each against a goal in percent in check.json) and fails CI below its goals. The maintainer asked for a name in the same style and on 2026-10-21 chose Assay over Hallmark, Touchstone and Gauge. On 2026-11-02 the name Assay went to reverse engineering instead (ADR Radical Assay: an assay finds what an ore is made of, as that tool finds the model in existing code), and the maintainer chose Hallmark for the check. `check` is already used by the CLI command, the CI job \"Architecture model\", `npm run check:architecture`, CLAUDE.md, the manual, Studio's Inspector, check.json and the model's own texts."
date: "2026-11-02"
decision: "The product formerly called radical check is named Radical Hallmark: a hallmark is the stamp an assay office strikes on metal that has met its standard, as the check passes a model only when its evidence meets the goals in check.json. The family reads as one workshop: Assay finds the model in existing code, Forge builds the model, Crucible searches for where the code breaks it, Hallmark stamps in CI how much of it is proven. The command becomes `radical hallmark`, and `radical check` stays as an alias for good, so existing CI jobs, scripts and documents keep working; check.json keeps its name. Recorded on 2026-10-21 (as Assay) and renamed on 2026-11-02 without a code change: until the rename is implemented the command, the CI job, the manual and the model's texts keep saying radical check."
