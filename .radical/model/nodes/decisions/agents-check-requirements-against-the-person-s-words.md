type: "adr"
label: "Agents check requirements against the person's words"
alternatives: "A reviewer with a language model in CI (independent, but needs an API key and costs at every pull request). A person reviewing in Studio's Inspector (most reliable, but only when someone looks). A deterministic rule in radical check (cannot judge meaning)."
consequences: "A requirement can be checked against what was said: by the agent when it writes it and again before the code, by radical check in CI for the quotes' presence, and by a person in Studio. The check of meaning is the agent's own reading, so some errors still pass; quotes make it cheaper and catch what was never turned into a requirement."
context: "An agent turns what a person says into EARS requirements and ADRs and then builds from those. In the benchmark, details the client stated (a value of 0, an e-mail address kept on the order) were changed on the way into requirements and decisions, and the code followed the changed text. The needs could not show it: they held the first request, and the answers to the agent's questions only in its own summary or nowhere."
date: "2026-11-12"
decision: "A need keeps the person's words: each question the agent asks about it and the person's answer go into its description word for word, not summarised. A requirement's derives relation to a need carries the words of the need it rests on (property quote, one verbatim fragment per line). Before it writes code, the agent calls review_requirements: it lists each requirement added or changed on the branch, and each one a changed need leads to, with its sentence next to the quoted words (the whole need where nothing is quoted) and the values that differ, and asks the agent to write down every value the requirement states with the words that say it and to correct a requirement whose words say something else. radical check reports a derives relation to a need without a quote (warning), a quote the need does not hold (error), an answer of a person in a need that no requirement quotes (warning), a hard value a quote says that its requirement does not (warning), and one the requirement says that no quote or its rationale says (warning)."
status: "accepted"
