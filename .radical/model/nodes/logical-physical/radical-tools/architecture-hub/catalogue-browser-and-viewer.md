apps/hub/src/HubApp.tsx. Group chips, Tags and Status facets, search and sort over the catalogue, cards grouped by concern group with a select toggle, and a selection basket with Add to Studio (opens studio.radical.tools?hub=<ids> in a new tab). An open pack shows in a dialog over the catalogue: read-only viewer (canvas, wiki, table) on the 'viewer' runtime profile, named-view selector, Fit and Smart Layout, Add to Studio, a Related bar and a read-only properties panel; Esc or the backdrop closes it. The pack's sources stay in its file and are not listed.
