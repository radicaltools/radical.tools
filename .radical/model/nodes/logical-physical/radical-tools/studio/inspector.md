The Inspector perspective (components/Inspector.tsx with components/inspector/: ModelTab, ImplementationTab, ThisChange, ChangesTab, SettingsTab, settingsDraft, shared; persistence/inspector.ts, navigation.ts): runs checkModel on the model as it is edited with the folder's check.json, .state/test-results.json and .state/measurements.json, shows it in the tabs Model quality and Implementation with a link to every element it names, which opens the properties card every perspective shows (ElementCard, read-only, with Show on canvas and Open wiki page; its links move the card, onNavigate; a card a link opened keeps its room on the page, with-card, while This branch's lies over it); when the folder holds a base, puts a Changes tab first and opens on it (the base and its age, with the commands that save it again when it is old, and every element added, changed with its fields and removed, and the relations; a click on an element opens Designer's properties card, read-only, with its changes and Show on canvas and Open wiki page, over the page so nothing beneath moves) and heads Implementation with This change (the requirements and ADRs changed since the base, each with what the tests say, and the new ones verified in the tab's label). Show on canvas (ShowOnCanvas, canvasViewsFor) offers the canvas views that show the element, the smallest first, and opens the one chosen. Edits check.json in Settings (goals, severities, baselines, test-unbound files; Ratchet; the change marked when it loosens the gate, and its diff) and saves it with saveCheckConfig, and the toolbar button with the error and warning counts, enabled by a check report, measurements or a base. Puts the check's evidence and findings by element into @radical/ui's useCardVerification for the card's Verification section in every perspective. Passes checkModel the Hub's concern packs from the catalogue the Hub store loads (fetched once a folder model is checked) and shows each unaddressed concern with its elements, its questions and Answer the questions…, which opens the Hub import dialog on the pack bound to the first element (openConcern, the radical:open-hub event the toolbar listens to). Path, in the card's Verification of a need, requirement, scenario, ADR or fitness function, opens the verification path (components/inspector/TracePanel.tsx: traceOf drawn in columns on a CSS grid, the lines between the cards in SVG from their measured places, a test's failure message and its link to VS Code where the repository's folder is known, Only what does not pass, Back over the paths opened from it); the element on it is part of the route (useInspectorNav.trace, the tr segment), and persistence/verificationPath.ts offers it to the card (openVerificationPath switches to the Inspector on the path; leaving the Inspector clears it). Its content is up to 1640 px wide.
