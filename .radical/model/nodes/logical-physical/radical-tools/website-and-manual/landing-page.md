apps/web/index.html and landing.css: the hero shows the product as one picture, a map. The Radical Model sits in the middle (its rules, elements, views, history and files), with a coloured branch and arrowheads to each part: Radical Studio and Radical MCP read and write it, Radical Hub packs concerns in, Radical CLI checks it, Radical Forge generates it, and it harnesses your code. What is yours stands dashed at the edges and uses the parts: your agent uses Radical MCP, which uses Forge, and writes your code; your CI, between the CLI and your code, runs the CLI and tests the code. Every box is a link; on a narrow screen the same map is one column. Its eyebrow starts with the released version, linked to the latest GitHub Release (what is new, the desktop installers). Under the map, after a thin line that fades at its ends, Open Studio in the browser, Download the desktop app (the latest GitHub Release) and Explore the Hub, then, after the same line, Get started: the one command that connects a coding agent from an empty folder in a tab per system, each with a Copy button that takes the command shown: macOS · Linux (curl radical.sh, sh radical.sh setup), Windows (curl.exe radical.cmd, radical.cmd setup; the tab shown first on Windows) and With Node.js (npx @radicaltools/cli setup). Loads theme.js before any stylesheet.
