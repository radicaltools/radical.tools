packages/layout: Smart Layout and the other headless layout engines, used by Studio and bundled into the MCP server. smartLayout.ts: the ensemble of ten engines (elkLayout.ts: five ELK layered variants, a metamodel-aware layered layout, stress, force, Mr.Tree; radicalLayout.ts: semantic C4), crossing minimisation by sibling swaps (crossingOpt.ts), the render-aware composite score (weights in scoreWeights.ts), simulated annealing in three phases (annealing.ts), finalisation that separates siblings and fits containers (layoutFinalize.ts) with room for relation labels (labelRoom.ts), and the relaxed winner as a last candidate. elkLayout.ts also has the hierarchical tree layout (applyTreeLayout). constraints.ts resolves and enforces row, column and grid alignments (enforceAlignments records what each pass moves, so only what the members then cover is pushed aside and only the frames round what moved are fitted; heldByPins names what pinned elements hold in place); viewInput.ts gives what a layout of one view sees and writes its result back (shared by Studio's store and the MCP server): placeOnViewCanvas places a view never laid out as Studio's canvas opens it, applyAlignments lines up a view's rows, columns and grids keeping pinned elements (the rule wins when its pinned members sit on different lines), and keptFrames names the frames a Tidy round a selection kept, which the refit after it leaves as drawn; tidy/layout.ts keepUnmoved gives back as drawn a frame where nothing moved; geometry.ts places new and imported elements (placeNewNode, freeSpotNear, createBatchPlacer, placeUnplaced). For the canvas: edgeRouting.ts (Bezier edges, A* routing around elements), portAllocator.ts (sides and spread connection points) and edgeLabels.ts (label sizes and placement). liveColaEngine.ts: the live WebCoLa physics (LiveColaEngine, which the canvas runs in a worker; calm and push drags, pins, alignments, holdByGroups) and relaxLayout, which Smart Layout scores as a candidate. The product's core IP.
