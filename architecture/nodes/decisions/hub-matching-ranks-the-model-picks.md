consequences: "On the holdout briefs keyword precision rose from 0.18 to 0.41 and recall from 0.23 to 0.44, and every expected concept now reaches the model (0.44 before). The clarify call grows by roughly 2-3k input tokens per stage. A wrong blueprint would lift the wrong concepts everywhere, so the threshold prefers none: it finds 1 of 3 on the holdout, and the model can still pick one from the C4 candidates. The synonym groups are hand-written and English; the index served by hub.radical.tools carries searchText only after the Hub is redeployed. The model's pick is measured only on demand, with a key."
context: "Radical Forge suggested Hub concepts by plain keyword overlap between the brief and each concept's name, description and tags. On a benchmark of 14 briefs only a third of the four suggestions per stage fitted (precision 0.33, recall 0.38), no blueprint was ever suggested, and briefs in Polish got nothing. Generic words (store, time, order) weighed as much as PSD2, blueprints were never searched, and the curated links between concepts (hubRefs) were unused."
date: "2026-10-08"
decision: "Matching takes two steps, shared by Studio and the MCP server (@radical/common src/ai/forge/hubMatches.ts and clarify.ts). A lexical ranking weighs each term by its rarity in the catalogue (IDF) and by field (name and tags 3, description 1.5, node content 1, via a searchText field the catalogue index now carries), stems words lightly and folds synonyms into groups. The blueprint that clearly fits the brief (score 25 and a 1.3x lead) is suggested first in the C4 stage and lifts the concepts it links to in every stage; a stage's best matches lift their links too. Then the model picks: the clarify call gets up to 60 ranked candidates per stage (every blueprint in C4) and picks at most five that fit, whatever the brief's language, which the user confirms. Without AI, or when the reply cannot be read, the best keyword matches are suggested. A benchmark in @radical/hub-catalogue (tuning briefs plus holdout briefs never tuned on) guards the ranking; an opt-in run scores the model's pick."
