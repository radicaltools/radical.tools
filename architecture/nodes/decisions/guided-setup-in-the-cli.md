label: "Guided setup in the CLI"
alternatives: "A shell script that does the setup itself (install.sh run with curl | sh): no Windows, JSON edited with sed or jq, and the steps written twice. The launchers keep to finding Node.js and running the CLI. Documentation only: where people got stuck. A Claude Desktop extension first: solves the PATH problem for one agent only."
consequences: "Works wherever the MCP server does, Windows included, with no curl | sh to trust. The place and format of each agent's configuration is code to keep up to date (CLIENTS in apps/cli/src/agentConfig.ts). A Claude Desktop extension (.mcpb) or a Claude Code plugin can follow as one-click paths writing the same entry. The launchers are two scripts to keep working per platform: radical.sh is tested with a stand-in Node.js mirror, radical.cmd runs in CI on windows-latest. A project that keeps its launcher keeps its version in one line."
context: "Connecting an agent took several hand edits: a JSON entry per agent, in a file whose place differs by agent and platform, an absolute path to node for Claude Desktop, which does not see the shell's PATH, and the git hooks for Studio's Changes on branch. The product owner asked whether a shell script that guides step by step would help."
date: "2026-10-27"
decision: "Guide the installation with `radical setup` in the published CLI (npx @radicaltools/cli setup), and check it with `radical setup --status`. Both are Node, in the package people already run: setup finds the agents installed, merges one entry into each configuration (JSON parsed and written back, a TOML section replaced), pins the MCP server to the CLI's version, and radical setup --status starts each server as its agent would. Every question has an option, so the same command runs unattended. The way in for someone without Node.js is a launcher, radical.sh (POSIX sh) or radical.cmd (Windows), downloaded from radical.tools into the new folder: it only finds Node.js 20.11 or later, or downloads the current Node.js 24 from nodejs.org after asking, checked against its SHA-256 sum, and runs the CLI through npx. radical setup run through it pins it to the CLI's version and starts the agents' servers through it, like a Gradle wrapper the project keeps."
status: "accepted"
