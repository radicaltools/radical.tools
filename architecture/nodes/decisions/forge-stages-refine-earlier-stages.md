The user keeps them all, rejects the chosen ones or all of them (rejectRefinements removes additions and restores old values; a deletion is only reported), in Studio's Refinements panel or over MCP with forge_reject_refinements; Regenerate undoes the previous attempt's changes too. forgeGaps runs radical check's completeness rules and Forge's own, only those of the stages done, and the gaps go to the user and into the next stage's task."
