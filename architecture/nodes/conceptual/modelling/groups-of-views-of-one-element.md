label: "Groups of views of one element"
action: "Studio and the MCP server shall make the view a group holding a view of each element of the viewpoint's types that is not external, each kept to its element and what lies inside it and named after it; add a view to the group as soon as such an element is added and remove it with the element; lay out each new canvas view of a group with Smart Layout (the MCP server as it makes it, Studio the first time it is opened in the designer without positions of its own); mark such viewpoints View per element in New view and such views in the list of views, list the group as one card that shows or hides its views on a click, opening its first view when made; keep the group's views in its folder (moving one of them to a folder moves the group) and in step with its viewpoint; keep the group's viewpoint, view type and filter and its views' viewpoint, view type, filter, name and elements as the viewpoint sets them (no View type, Viewpoint list, Detach, filter editing, renaming or hiding an element there; over MCP such changes are refused); delete them with the group; and the metamodel editor (View per element) and upsert_viewpoint (subjectTypes) shall let a viewpoint make a view of each element of chosen types."
ears_type: "event-driven"
rationale: "A state machine, a process, a system's containers and a container's components read on their own, as C4 draws them, and the list of views stays one entry per viewpoint however many there are; a new container shows up in its group without anyone making a view. Evidence: packages/common/src/model.ts (isViewGroup, planViewGroups, syncViewGroups, applyViewpoint, deleteNode), packages/common/src/viewpoints.ts (scopedChain, subjectViewName), packages/common/src/ai/modelFacade.ts, packages/ui/src/store/diagramStore.ts (_sync), packages/ui/src/components/RightPanel.tsx (group card, Group note), packages/common/src/ai/tools/viewTools.ts, apps/studio/src/renderer/src/components/MetamodelEditor.tsx"
trigger: "the user or an agent makes a view of a viewpoint that draws one element (New view, the Viewpoint list, create_view or update_view)"
