type: "requirement"
label: "Long fields are Markdown"
action: "Studio shall read an element's description and every textarea property as Markdown: the wiki renders them (paragraphs, line breaks as written, lists, emphasis, code, quotes, tables, links opening outside the app and links into the app (#/) opening here, a remote image (one whose address the browser would resolve to another host, in any form: http(s)://host, //host, https:host, https:/host, \\\\host or /\\host) shown as a link with its address and never fetched, data: and local images shown, a link emptied by sanitising and raw HTML shown as text) and edits them as written on a click; the table's summary renders inline Markdown, its template's own text included, a plain value escaped into it and its tooltip plain text; a card on the canvas shows the text without its marks; and a textarea in the properties panel says it takes Markdown."
ears_type: "ubiquitous"
rationale: "Descriptions and ADR fields are prose, and the description already is the Markdown body of an element's file in a folder model; bold, lists and links make them readable where they are read. A remote image in a field was fetched when the page showed it, telling a third party who reads the model; the maintainer decided on 2026-10-21 (D13, exploratory runs 45 to 64) that it is shown as a link and nothing is fetched. Exploratory runs 65 to 69 (2026-10-21, item 244) found images fetched from another host through address forms the check missed (https:host, \\\\host). Evidence: packages/common/src/markdown.ts (isMarkdownField, markdownToPlain, escapeMarkdown, keepLineBreaks, isRemoteUrl), packages/common/src/nodeSummary.ts, packages/ui/src/components/MarkdownText.tsx (markdown-to-jsx, remote images as links), packages/ui/src/components/WikiView.tsx (InlineText, partSummary), packages/ui/src/components/TableView.tsx (renderSummary), packages/ui/src/store/diagramStore.ts (plainDescription), packages/ui/src/components/RightPanel.tsx (MARKDOWN_HINT), apps/studio/src/renderer/src/components/MetamodelEditor.tsx (SummaryField)"
