"I would like you to improve the views Forge makes. 1. There is no structure view of the state machines at all; I would like one, but one view per machine, not one with all of them. 2. The process view: it is there, but I want one per process. 3. The same for C4: the container view should be per container, right? Apply the same wherever it makes sense; what do you propose?" After the proposal (a viewpoint drawn for one element, its views scoped to that element; State machine, Process, Containers of a system, Components of a container, Entities of a domain): keep the views of the whole model in New view but have Forge make only the per-element ones, do the domains now too, and let a view's name follow its element's until it is renamed. Then: "I'd like this implemented differently: still one view, but when I click it I get, say, 5 views, and when I add a container a 6th appears there by itself." Settled: a view as soon as the element is added (not external ones), and only the group, no single picked element.
Translated from Polish.
