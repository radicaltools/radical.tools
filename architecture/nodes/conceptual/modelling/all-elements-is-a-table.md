type: "requirement"
label: "All elements is a table"
action: "Studio shall always list, first among the views and not deletable, All elements: the whole model as a table by containment, with the + rows to add and the properties card on a double-click; open a model (from a file, a folder, the list of models, the recent models or a ?hub= link) on its first view in model order, and on All elements only when it has no views; and make + New view's blank view a table of the whole model too, a canvas of the whole model being a structure view that lists no elements."
ears_type: "ubiquitous"
rationale: "There must always be a complete reading of the model to fall back to, and new elements an agent adds must show somewhere at once. A canvas of every element was rarely readable and was a layout to keep up; a table lists everything without arranging, and a user who wants the whole model drawn makes a structure view of it. Links to the former canvas (#/…/v/canvas) open All elements. A model opened on All elements showed a long table instead of the picture its author made first; the maintainer decided on 2026-10-21 (D8, exploratory runs 45 to 64) that a model opens on its first view. Evidence: apps/studio/src/renderer/src/App.tsx (activeViewKind), apps/studio/src/renderer/src/route.ts (ALL_ELEMENTS), packages/ui/src/components/RightPanel.tsx (ViewList, New view), packages/ui/src/store/diagramStore.ts (addView, suggestSmartLayoutIfUnarranged, first view on load), packages/layout/src/viewInput.ts; apps/studio/tests/route.test.ts; manual#views"
