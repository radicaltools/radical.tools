type: "requirement"
label: "Studio waits for the agent"
action: "Studio shall hold its own saves, say once that it waits for the agent, merge its edits into each of the agent's changes it reloads, and save them once the agent pauses, holding them at most 15 seconds from when it first sees a mark that lies further ahead (a server whose clock runs ahead); when the page goes away (a reload, a closed tab) it shall write them at once, merged, and keep them in the browser until a save lands, merging them into the folder's model when it is opened next; and the MCP server shall mark the folder as written by an agent after each write."
ears_type: "state-driven"
precondition: "an agent has written the open folder model over MCP in the last 15 seconds (.radical/agent-activity.json)"
rationale: "While an agent works, every Studio save would meet a folder that changed since it was read; holding them leaves the agent's writes alone, and the reload merge keeps the user's edits. A reload during the hold lost them (exploratory run 29, 2026-10-20): since writes merge, leaving the page writes at once, and the browser keeps the edits in case the write cannot land in time. A server whose clock ran an hour ahead held Studio's saves for the hour, each check cutting the mark to 15 s from then (exploratory runs 65 to 69, 2026-10-21, item 237). Evidence: apps/mcp/src/folderModel.ts (markAgentWriting), packages/common/src/formats/agentActivity.ts (agentWritingUntil), apps/studio/src/renderer/src/persistence/autosave.ts (flushPersist, holdForAgent, flushSync, keepEdits, takeKeptEdits), packages/common/src/modelMerge.ts (modelEdits, mergeModelEdits), apps/studio/src/renderer/src/store/documentStore.ts (agentWritingUntil, agentMarksSeen), apps/studio/src/main/index.ts (folder:read-agent-activity)"
