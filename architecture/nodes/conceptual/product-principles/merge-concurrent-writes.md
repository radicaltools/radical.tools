type: "requirement"
label: "Merge concurrent writes"
action: "The system shall merge its change with the outside one element by element and field by field (relations, views, sequences, presentations and milestones by id, positions element by element, a view's element lists and the metamodel's lists of ids such as viewpoints, allowed parents and enum options as sets, a sequence's steps and notes as one list of steps, an empty value as no value), keep the outside value of a field both changed and name it, delete an element or relation one side deleted and the other changed (the delete wins) and name whose change was dropped, bring back a container one side deleted when the other added an element into it, with its relations and places, and say so, write the merged model, and refuse the write only when the folder does not read as a model; processes writing one folder from disk (MCP servers, the desktop app) take turns through .radical/write.lock, so none loses another's write, taking over a lock that names no turn once it is past being written."
ears_type: "unwanted-behaviour"
rationale: "Model files are edited in other editors, by git and by coding agents, often while Studio has the folder open; the two sides nearly always change different elements. The maintainer decided on 2026-10-21 (D9, exploratory runs 45 to 64) that a delete wins over the other side's edit, with a notice, and that a child added into a container the other side deleted rescues the container; the same runs found deletes made on both sides reported as conflicts (item 173), a view emptied on both sides turning into a view of every element (item 174) and a note moving to another step of the same relation (item 204). Evidence: packages/common/src/modelMerge.ts (mergeModels, ID_SET_KEYS, mergeViewNodes), packages/common/src/formats/mdFolderSync.ts (MdFolderSession.write merge, mergeMdFolderFiles), apps/studio/src/main/index.ts, apps/studio/src/renderer/src/store/documentStore.ts, apps/mcp/src/folderModel.ts (commit), packages/node-files/src/diskFolderStorage.ts"
unwanted_condition: "a model file changed outside the app since the app read it"
