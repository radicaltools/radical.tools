Radical tools as part of a wider SDLC: specification, harness, exploratory tests, e2e tests, fitness functions. A `radical check` command in the radical CLI, run in CI, checks the model: is it consistent, is the trail from need to check complete, and (later) do the tests the model points at pass. Studio keeps the model consistent while it is edited; the check covers what Studio cannot (merges, hand edits, completeness).
