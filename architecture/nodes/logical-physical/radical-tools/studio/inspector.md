The Inspector perspective (components/Inspector.tsx with components/inspector/: ModelTab, ImplementationTab, ThisChange, ChangesTab, SettingsTab, settingsDraft, shared; persistence/inspector.ts, navigation.ts): runs checkModel on the model as it is edited with the folder's check.json, .radical/test-results.json and .radical/measurements.json, shows it in the tabs Model quality and Implementation with a link to every element it names (its panel, Peek); when the folder holds a base, puts a Changes tab first and opens on it (the base and its age, with the commands that save it again when it is old, and every element added, changed with its fields and removed, and the relations; a click on an element opens Designer's properties card, read-only, with its changes and Show on canvas and Open wiki page, over the page so nothing beneath moves) and heads Implementation with This change (the requirements and ADRs changed since the base, each with what the tests say, and the new ones verified in the tab's label). Show on canvas (ShowOnCanvas, canvasViewsFor) offers the canvas views that show the element, the smallest first, and opens the one chosen. Edits check.json in Settings (goals, severities, baselines, test-unbound files; Ratchet; the change marked when it loosens the gate, and its diff) and saves it with saveCheckConfig, and the toolbar button with the error and warning counts, enabled by a check report, measurements or a base. The element's Peek lists its checks: each condition with its outcome and, for a measured value, the value, the sensor and its age. Passes checkModel the Hub's concern packs from the catalogue the Hub store loads (fetched once a folder model is checked) and shows each unaddressed concern with its elements, its questions and Answer the questions…, which opens the Hub import dialog on the pack bound to the first element (openConcern, the radical:open-hub event the toolbar listens to). Its content is up to 1640 px wide.
