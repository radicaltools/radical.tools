packages/ui/src/components/RightPanel.tsx (LeftPanel and RightPanel), ViewPipelinePanel, NodeWizard, EarsQuickEntry, RefPicker, propertiesCover.ts. On the left an accordion of Views, Milestones and Sequences — each with its icon, colour and count, a folded one saying what it holds, the open one taking the free height — with All elements (the whole model as a table) first, view cards coloured by view type (while Changes on branch is on, each with the number of changed elements it shows), + New view (a blank table or one of the metamodel's viewpoints) and the properties of a view (name, folder, lines, viewpoint, view type, layout and its Filter: a chain of levels with their filters, the order; read-only with Detach for a view of a viewpoint, Save as viewpoint otherwise) or a milestone. Over the right side of the view, the properties card of the one selected element, relation or sequence: it slides in on a selection and out without one, never resizing the view; its head holds the type, the name edited in place, where it sits, a Wizard button and a ⋯ menu; while Changes on branch is on, a section under it says the element is new or lists each changed field with the words removed and added since the base; its attributes are rows edited in place, long fields Markdown (EARS editor, wireframe, Hub template section). The card's width is kept as --rp-width on the layout, so what else lies over the view keeps clear of it. The node-creation wizard. The Elements palette is part of the canvas (ElementPalette).
