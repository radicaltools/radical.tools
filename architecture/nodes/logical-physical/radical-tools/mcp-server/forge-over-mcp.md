apps/mcp/src/forge.ts. The forge_* tools (forge_start, forge_clarify, forge_generate, forge_propose_refinement, forge_answer_refinement, forge_complete_stage, forge_arrange, forge_wireframe, forge_import_hub_concept, forge_finish) and FORGE_PROCEDURE, the text of the forge prompt, which has the agent ask the user first for the languages to talk and model in, then for the view structure. Keeps one run in memory (need, languages, answers, stage summaries, the model before each stage, the open proposal, what each stage added and refined, the concern packs it imported), refuses steps out of order, hands the agent the shared clarify and stage prompts with the run's languages, the open gaps and, in the Requirements stage, the Hub's concern packs and their questions from the catalogue the build bundles; imports the packs the user confirmed whole and unbound before the Requirements stage, tells every later stage which concerns are decided and the C4 stage what to link, and after C4 binds what is still unbound where each pack's trigger points. Keeps a proposed refinement until the agent brings the user's answer and applies it only when accepted, refuses the catalogue tools' direct writes to earlier stages while a stage is open (guard), files each stage's elements into the Forge views with a place beside what they already show, and after every step writes .radical/forge-run.json for Studio. forge_import_hub_concept imports a concern pack with the answers, bound to the elements given or unbound.
