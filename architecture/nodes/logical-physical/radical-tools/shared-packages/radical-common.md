The model shared by every app: C4 types, the two built-in metamodels (Radical and C4) with their validator, statechart and aggregate rules, EARS sentences and wizards, file formats (Markdown-folder sync, Structurizr DSL import, Gherkin export, and the .radical/ editor-state formats for the canvas selection and the Forge run status), query language, the headless model facade, the AI tool catalogue and system prompt, Radical Forge's stages, prompts, views and Hub matching, the Hub concept import, radical check's rule catalogue, report readers and evidence (src/check), and the model change report (src/modelChanges.ts: what changed between two versions of a model, layout left out, with old and new values, ancestors and relations). No UI or browser dependencies.
