The model shared by every app: C4 types, the two built-in metamodels (Radical and C4) with their validator, statechart and aggregate rules, EARS sentences and wizards, file formats (Markdown-folder sync with its format version MD_FOLDER_FORMAT_VERSION, Structurizr DSL import, Gherkin export, and the .radical/ editor-state formats for the canvas selection, the Forge run status, the agent's activity with its server's version and the model's base, formats/modelBase.ts), query language, the headless model facade, the AI tool catalogue and system prompt, the views a new model starts with (src/viewStructure.ts: metamodelViews makes a view of each chosen viewpoint in its folder, a group for one that draws one element), Radical Forge's stages, prompts, views and concern packs (src/ai/forge/concerns.ts: the packs offered in clarify, their questions, what later stages are told, the binding after C4), the Hub's concern packs (src/concerns.ts: CONCERN_GROUPS, triggers, where the model stands on each concern, the answers' variant, bind suggestions, the import bound to any number of elements, the standard a pack meets) and the concept import they rest on, radical check's rule catalogue with concern-unaddressed and concern-unbound, report readers and evidence, the conditions of metrics and the measurements they are evaluated against (src/check, src/check/metrics.ts; elements and relations with an origin are checked with the model and what is found about them left out), the reading of models from before metrics (src/formats/checksMigration.ts: tests into test() lines, a threshold into the description), the model change report (src/modelChanges.ts: what changed between two versions of a model, layout left out, with old and new values, ancestors and relations) and the branch's changes in Studio (src/branchChanges.ts: marks and ghosts, the changes per view, the words that changed, and how far each changed requirement and ADR has got by the test report) and the federation of models (src/federation.ts: deps.json, composeFederation marks the dependencies' elements and relations with their origin, the .radical/federation.json format and withOtherModels, which adds them to a model read from its folder; model.ts originOf, ownModel, which the Markdown-folder serializer applies so that nothing of theirs is written, and the read-only rules every check* function applies to them). The pure wiki document builder (src/wikiDocument.ts) supplies Studio and CLI exports with the same scope, hierarchy, fields, requirement prose, relationship groups and content blocks. The Radical metamodel's Process group (process and step with order, repeat, condition and how their children run; performed-by) and the Warnier tree (src/warnier.ts: warnierRows takes a view's chain, or its elements by containment, warnierTree orders siblings and reads repetition, alternatives and concurrency, a state machine's too) that the Warnier view draws. The product version at run time (src/version.ts: buildInfo reads the build's __RADICAL_BUILD__, displayVersion shows a release bare and any other build as <version>+<commit>, compareVersions orders versions by SemVer with build metadata left out). No UI or browser dependencies. The search of a model (src/search.ts: searchModel finds views, folders, elements, relations, sequences, presentations, slides and milestones by every word, without case or accents, by initials, with the prefixes v: f: e: r: s: p: m: @ in: type: and a property's value; searchSuggestions completes the word typed), used by Quick Search, the find bar and the query language's FIND.
