## Steps

1. Open → Sample model, switch to Presenter
2. Double-click the first slide's name in the dock, type a new name
3. Press F5, then Cmd+P (Ctrl+P elsewhere)

## What differs

```text
Expected: As in the presentation's own name field (✎) and every field fixed by F-0068: F5 and Cmd/Ctrl+P prevented, taken by Studio (F5 presents, Cmd/Ctrl+P = Quick Search)
Actual: Slide name field: F5 defaultPrevented=false, Meta+P defaultPrevented=false; presentation name field: both true. The field stays open with the typed 'Opening slide'
Seen: 2 of 2
Where it probably comes from: apps/studio/src/renderer/src/components/PresentationBar.tsx SlideCard: the name input's onKeyDown calls e.stopPropagation() on every key; it should call keepKeysHere(e) as DiscussionPanel and MilestoneChip do
A test that would catch it: apps/e2e/tests/studio/presentation.spec.ts: in Presenter, rename a slide, dispatch F5 and Mod+P in the input, assert defaultPrevented is true for both and the draft survives
```

## Fixed (2026-10-26)

The slide name field uses keepKeysHere, so F5 and Cmd/Ctrl+P reach Studio, and F5 saves the name and presents.
