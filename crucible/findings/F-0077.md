## Steps

1. Open the sample, view System Context
2. Lines Orthogonal (also happens curved)
3. Smart Layout

## What differs

```text
Expected: no relation label over an element; Tidy keeps room for the labels or counts the overlap
Actual: before 0 labels over elements, after 4: gap 99 px for the 156x35 label 'Identity & AML screening', gap 102 px in one row for the 160x50 'Views accounts & transfers', each ~1000-1440 px² over both ends; Tidy reports lbl=0.13 and a rerun says already scores best (curved: 2 labels over, gap 124, lbl=0.00)
Seen: 3 of 3 orthogonal, 1 of 1 curved
Where it probably comes from: packages/layout/src/tidy/cost.ts labelOver skips the line's own ends (id === p.a || id === p.b); labelBox height 24 ignores the technology line, while the canvas's placeEdgeLabels avoids every leaf (guess)
A test that would catch it: packages/layout/tests/tidy/tidy.test.ts: System Context after runTidyLayout, placeEdgeLabels puts no label over a leaf (or the labels part counts it); apps/e2e/tests/studio/layout.spec.ts: no .relation-label box meets an element after Smart Layout
```

## Fixed (2026-10-26)

Tidy's label cost sizes a label as the canvas draws it and counts it over the line's own ends and over frame headers as placeEdgeLabels does, so System Context keeps room for its labels in both line styles; labels that show only a type name are a follow-up.
