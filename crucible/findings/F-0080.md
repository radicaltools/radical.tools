## Steps

1. Open → Sample model; add a whole-model view placed as All elements places it
2. Save that document as a Markdown model folder; call smart_layout {viewId} through the MCP server
3. Run Smart Layout on the same view in Studio from the same document
4. Compare the view's positions

## What differs

```text
Expected: The same layout from both, in comparable time
Actual: MCP: 192–203 s ('crossings 3235 -> 3108, overdraws 716 -> 788'); Studio: 10 s ('772 moves in 10 s'); 255 of 283 elements are placed differently, median 2188 px apart, farthest 6795 px; an MCP client with the SDK's default 60 s timeout gets 'Request timed out'
Seen: 2 of 2
Where it probably comes from: Studio passes budgetMs TIDY_BUDGET_MS (10 s) in diagramStore.ts runSmartLayout; apps/mcp/src/folderModel.ts:626 calls runTidyLayout with no budget (guess)
A test that would catch it: apps/mcp/src/folderModel.test.ts: smart_layout on a model of more than 120 tangled elements returns the positions runTidyLayout gives with Studio's options (budget included) and finishes within that budget
```

## Also seen by run 189

Run 189 found the same independently (`f2-budget-parity.mjs`, MCP 189–190 s, 255 of 283 positions differ). Its addition: Studio's own move count varied 770 / 771 / 773 between fresh pages, so with a 10 s budget the result depends on the machine's speed, while the requirement "Same layout every run" asks for budgets in units of work rather than time. Whether the MCP server takes Studio's time budget or both count the budget in work is the maintainer's decision.

## Decision (maintainer, 2026-10-26)

The budget is counted in units of work (moves or evaluations), not seconds, in Studio and in the MCP server alike, so the same view gets the same layout on any machine, as the requirement "Same layout every run" says. The MCP server uses Studio's budget.

## Fixed (2026-10-26)

Tidy's budget is counted in work (moves judged, weighted by the view's elements), and Studio and the MCP server both pass TIDY_BUDGET, so smart_layout gives Studio's layout of a view on any machine in comparable time (0 of 283 differ).
